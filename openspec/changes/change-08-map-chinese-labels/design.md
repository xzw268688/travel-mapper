## Context

见 `proposal.md`。现状：`MapView.vue` 的提示用 `stat.countryName`（有数据时中文），无数据时用 `params.name`（英文）；悬停高亮标签始终是底图英文名。底图有 217 个要素，业务目录暂时只有 9 个国家。

## Decisions

### 1. 名称解析集中到一个纯函数

优先级：目录中文名 → 内置对照表 → 底图原名。目录优先是为了保证和下拉框、抽屉、图例完全一致；对照表只负责“翻译”，不参与业务判断。

### 2. 对照表作为前端静态资源

放在 `frontend/src/assets/world-names-zh.json`，键是底图 `properties.name` 原值。只在前端使用，不改数据库、不影响后端接口。

### 3. 标签只在悬停时出现

不启用常驻标签：217 个国家会互相遮挡。悬停标签用白色文字 + 深色描边，保证在深灰板块与浅色海洋上都可读。

### 4. 用脚本保证覆盖率

`scripts/check-world-names.mjs` 读取底图与对照表，输出未覆盖的要素名并以非 0 退出。这样以后替换底图时能立刻发现缺口。

## Risks / Trade-offs

- **底图升级导致名称变化** → 校验脚本会列出新增名称，按提示补映射即可。
- **敏感地区名称** → 仅做语言翻译，名称与底图一致；合规确认仍在上线前进行。
- **对照表体积** → 约 215 条键值，压缩后很小，不影响首屏。

## Migration Plan

纯前端改动，构建后发布即可；回滚只需回退前端版本。
