## Why

国家抽屉底部的“未归组”是内部术语，用户看到后不知道它指什么；下面还固定罗列“游记 0 · 消费 0 · 花费 ¥0.00”，在只有一条未归组行程时显得冗余。时间线卡片上也使用了同一个生词标签。

## What Changes

- 国家抽屉顶部的国家状态标签改为与图例一致：**“无记录 / 仅有行程 / 有游记”**，不再使用“未点亮 / 计划中 / 已完成”，避免和旅行状态一词两义。
- 旅行分组标题改为 **“计划中的旅行” / “已完成的旅行”**，并加一句 **“旅行状态由你手动标记”**；状态仍由用户手动切换。
- 移除抽屉底部单独的“未加入旅行”块，改为在顶部汇总下显示分类提示，例如 **“另有 1 条行程、2 篇游记未加入旅行”**；只显示非零项，不提供跳转。
- 时间线行程卡上的“未归组”标签同步改为“未加入旅行”。
- 未加入旅行的数据仍可在时间线、游记、记账页面查看。
- 仅调整前端文案与展示，不修改后端接口、DTO、领域字段或数据行为。
