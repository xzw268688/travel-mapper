## Context

见 `proposal.md`。抽屉数据仍按“旅行 → 城市”返回，本次只改渲染。

## Decisions

1. 用 `drawer.trips.length > 1` 决定是否显示旅行层。单次旅行时省略旅行标题与链接，直接渲染城市区块。
2. 单次旅行仍显示该次旅行的花费合计，避免用户误以为只统计城市。
3. `/trips/:id` 路由保留，供多次旅行时进入；单次旅行场景不再暴露入口。

## Risks / Trade-offs

- **单次旅行失去详情入口** → 抽屉已平铺全部内容，详情页只是重复展示；需要时仍可直接访问 URL。
- **多次旅行不变** → 现有分组逻辑与 E2E 不受影响。
